# Samsung-native production target

The factory targets six 1440x3040 UI screens per concept: Lock, Home, Messages, Dialer, Contacts, Settings, plus eight redesigned app icons.

Automate: art briefs, asset validation, UI-screen inputs, metadata, screenshots, QA, Android engineering-host builds, and Samsung handoff folders.

Account-gated: Galaxy Themes Studio access, final Themes Studio import/export, initial Seller Portal registration/review, and Samsung attestations.

Never mark a collection SELLABLE merely because the Gradle host builds. SELLABLE requires the COMPLETE_THEME_CONSTITUTION and an actual Samsung-authorized store package.
